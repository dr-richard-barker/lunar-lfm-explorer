Core Scientific Innovations

☀️

Acquisition Geometry as Explicit Context

Lunar appearance is dominated by solar illumination angles rather than intrinsic surface variations. The model tokenizes incidence, emission, phase, and azimuth as sequence inputs, so it is given the dominant illumination confound rather than having to infer it (model card).

🔍

Joint Mixed-Resolution Pretraining

A single set of weights covers both regional WAC (~100 m/px) and meter-scale NAC (~1 m/px) in a single pretraining loop, bridging a 100× spatial scale gap.

🧩

FlexiViT & Modality Decoupling

FlexiViT patch embedding lets you resize patch grids (e.g. ps8 for higher dense resolution) without backbone retraining; late-fusion tokenization allows dropping or adding modalities at fine-tuning time.

Multimodal Token Late Fusion

Tokens are embedded per-modality and concatenated along the sequence dimension:

Dense Image Tokens (5 × 256 = 1,280 tokens)
Optical metadata (8 fields, ≤10 tokens)
Static-map context (28 fields, ≤31 tokens)
Late fusion: baselines stack all layers as channels at a shared stem. NASA-IBM LFM gives each modality its own patch adapter and concatenates tokens along the sequence axis, so modalities can be dropped or added at fine-tuning time (model card). Context lengths ≤10 and ≤31 are the max_length values in the released backbone/config.yaml.

Candidate Landing Regions near Shackleton

Shackleton crater is centred at 89.67°S, 129.78°E, with a 20.92 km diameter (IAU Gazetteer). NASA named the three regions below among 13 Artemis III candidate landing regions in August 2022; none of them is in NASA's updated list of 9 regions (October 2024).

What This Explorer Does and Does Not Show

This repository holds no slope, illumination, Earth-visibility or rock-abundance data for these regions, so it shows none, and it gives no safety ratings.

Model card disclosure

The NASA-IBM LFM is "not validated for operational decisions such as landing-site certification or hazard clearance". The model card reports no landing-hazard or shadow-disambiguation evaluation, and this repository has run none.

Why polar lighting is hard

At Shackleton's latitude the Sun is never more than about 1.9° above the horizon (0.33° from the pole plus the Moon's 1.54° axial tilt), so long shadows dominate. The model takes each tile's illumination angles as input tokens rather than having to infer them from the image.
